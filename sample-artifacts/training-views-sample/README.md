# Training-view sample (SFT)

Twelve rows showing how a scenario plus its label becomes a supervised
training row in the tinker-cookbook chat JSONL shape ({"messages": [...]}).
Generated by scripts/export-sft.mjs from the public v2026-05 scenario set.
Regenerate the tracked sample with:

```bash
node scripts/generate-training-view-sample.mjs
```

What this is: a format demonstration of the scenario-to-training-view path.

What this is not: a training dataset, a training result, or a claim that
any model was trained. Labels carry label_source
"benchmark-owner-pre-gold" in the provenance sidecar; rows regenerate with
one command after the three-rater corroboration pass lands. No partition of
the published v2026-05 set functions as a held-out test set.

This working sample currently proves only the Checkpoint-2 transport and
opaque-render path. It is not cleared for training. Warning semantics,
evidence payload rendering, confidence removal, and legacy-row repair remain
pending in Checkpoints 3 and 4; rows may therefore contain conflicts those
checkpoints are explicitly required to resolve.
